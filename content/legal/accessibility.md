We build this site to the same standard we hold client work to, described on our [about](/about) page. This statement says plainly what that means and where we know we still fall short.

## What we aim for

This site targets **WCAG 2.2 Level AA**, the standard most commonly required by law and by the businesses we work with. In practice that means:

- Every page can be used with a keyboard alone, including the menu, the accordion on the questions page, and the contact form.
- Every interactive element has a visible focus indicator, so a keyboard user can always see where they are.
- Colour is never the only way information is shown. A severity label, for instance, carries text as well as colour.
- Text and background colours meet the required contrast ratio in both the light and dark themes we offer.
- Every image that carries meaning has real, descriptive alternative text. Decorative images are marked so a screen reader skips them.
- Headings are structured in order on every page, with exactly one main heading, so a screen reader user can navigate by heading the way a sighted user scans a page visually.
- Movement is avoided where it is not needed, and any animation respects your operating system's reduced motion setting.
- Forms use real labels rather than placeholder text standing in for a label, and errors are announced to assistive technology, not just shown visually.

## How we check this

We test with a keyboard, with automated contrast checking across every page in both themes, and by reading the site's structure the way a screen reader would present it. This is not outsourced to a plugin we install and forget about; it is checked as part of building each page.

## Where we know we fall short

We would rather say this plainly than claim perfection. As of the date above, we have not completed a manual test with a screen reader across every page, only automated and structural checks. If you use a screen reader and find something that does not work the way it should, we want to know, and we will treat it as a priority fix rather than a someday item.

## Telling us about a problem

If you hit an accessibility barrier anywhere on this site, email hello@altrazen.com with the page and what happened. We reply within one working day, the same commitment we make for any other enquiry.

## Changes

We update this statement as the site changes and as we complete further testing, rather than leaving it as a one-time claim.
